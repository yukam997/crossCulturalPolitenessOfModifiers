Which file do I load?

Any CSV with one row per trial. Required columns: predicate, attitude, relationship. Optional but recommended: subject_id, sentence, modifier_response_list (or modifier_response), trial_feedback, is_practice. Column order does not matter and extra columns are ignored.

The output of export_responses.py works as-is. From Numbers or Excel, use File → Export → CSV. Answers may be a JSON array (["quite","a bit"]) or semicolon-separated (quite; a bit).
